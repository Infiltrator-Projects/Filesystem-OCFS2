# Filesystem-OCFS2

Independent native Common V2 offline reader development. Recognition verifies superblock geometry, generations and root/system dinodes. The new bounded local reader implements direct and indirect extent mapping, inline files/directories, native global cluster bitmap traversal with coverage and counter reconciliation, local journal clean-state checks, and CORE mount/stat/list/read plus VOLUME query. Initial mount profile is 4 KiB blocks/clusters, one local slot, no indexed directories, xattrs or refcount trees. Dirty journal, clustered, multi-slot and unsupported feature profiles are refused. Exact-source independent image and populated payload tests must establish qualification before runtime publication; the v0.1.0 runtime candidate remains gated on exact-revision CI and package checks; the v0.0.1 PDF-only release remains immutable. No native mutation, defragmentation, journal replay or physical BOOT/kernel qualification is claimed.
